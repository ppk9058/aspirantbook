# TrillionSkill Release Notes

**Document status:** Release-note template and release policy  
**Audience:** Users, support, operations, product

## Release record
| Field | Value |
|---|---|
| Version/build | TBD per release |
| Release date and time zone | TBD |
| Environment | DEV / TEST / UAT / PROD — identify exactly |
| Commit/tag | TBD |
| Release owner and approver | TBD |
| Change window and communication | TBD |

## What changed
List user-visible changes in plain language. Separate shipped capability from code-only or configuration changes. Link requirement IDs and test evidence.

## Fixes and known limitations
Record resolved defects, remaining defects, feature flags, provider dependencies, browser/device limits, and support guidance. Do not promise a feature that lacks UAT evidence.

## Data and operational impact
List migrations, backfills, content changes, provider credential changes, new monitoring, expected user impact, backup reference, rollback trigger, and rollback owner.

## Verification and approvals
Attach test plan results, accessibility/visual evidence for touched screens, security review, migration verification, and release approval. No production release is approved by this blank template.
