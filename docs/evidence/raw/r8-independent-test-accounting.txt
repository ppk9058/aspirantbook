--------------------------------------------------------------------------------

Root cause: `node --test <file...>` treats `node_modules/.bin/tsx` as a test
file and loads every *.test.ts with plain Node (no tsx loader, no tsconfig
`@/*` path alias), so almost every suite dies at import time:
  Error [ERR_MODULE_NOT_FOUND]: Cannot find module '<root>/lib/...'
  Error [ERR_MODULE_NOT_FOUND]: Cannot find package '@/lib' imported from
                                 tests/unit/test-db-guard.test.ts
The working invocation used by the existing script `test:content-engine`
(package.json) is `tsx --test ...`. G3's recorded evidence
(docs/evidence/raw/ci-additions-verify.txt) has sections 1-8 and NO unit-test
section at all, i.e. this command was never executed before this measurement.
